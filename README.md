Problem: make your small image recognition neural network

Data: MNIST (https://huggingface.co/datasets/ylecun/mnist, https://docs.pytorch.org/vision/stable/generated/torchvision.datasets.MNIST.html)

Note: train on the train part, test on the test part!!!

Models to play with:

A shallow Multi-Layer Perceptron (MLP)
Convolutional Neural Network (CNN)
Transformer (Encoder)
Additionally, there is good opportunity to add test "%" by doing different image augmentations.
